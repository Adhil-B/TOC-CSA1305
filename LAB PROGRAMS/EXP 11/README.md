# Experiment 11: Simulation of PDA for $a^n b^{2n}$

## Aim

To design a Pushdown Automaton (PDA) using a simulator to accept the input string $a^n b^{2n}$ where $n \ge 1$.

---

## Problem Statement

Design a PDA for the language $L = \{ a^n b^{2n} \mid n \ge 1 \}$.
