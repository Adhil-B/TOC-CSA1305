# Experiment 20: Simulation of DFA for Strings Ending with 'ab'

## Aim

To design a Deterministic Finite Automaton (DFA) using a simulator to accept strings ending with 'ab' over the alphabet $\{a, b\}$.

---

## Problem Statement

Design a DFA for the language of strings over $\{a, b\}$ that end with the substring 'ab'.
