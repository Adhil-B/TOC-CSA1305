# Experiment 13: Simulation of Turing Machine for $a^n b^{2n}$

## Aim

To design a Turing Machine (TM) using a simulator to accept the input string $a^n b^{2n}$ where $n \ge 1$.

## Problem Statement

Design a TM for the language $L = \{ a^n b^{2n} \mid n \ge 1 \}$.
