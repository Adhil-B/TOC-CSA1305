# Experiment 19: Simulation of DFA for Odd Number of 'a's

## Aim

To design a Deterministic Finite Automaton (DFA) using a simulator to accept strings with an odd number of 'a's.

---

## Problem Statement

Design a DFA for the language of strings over $\{a, b\}$ containing an odd number of 'a's.
