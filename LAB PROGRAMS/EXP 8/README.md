# Experiment 8: Checking Whether a String Belongs to the Context-Free Grammar (CFG)

## Aim

To write a C program to check whether a given binary string belongs to the language defined by the Context-Free Grammar (CFG):

```
S ? A101A
A ? 0A | 1A | e
```

---

## Problem Statement

Write a C program to check whether a given string belongs to the language generated by the Context-Free Grammar:

```
S ? A101A
A ? 0A | 1A | e
```

---

## Theory

A **Context-Free Grammar (CFG)** is a formal grammar used to generate strings of a language.

The given grammar is:

```
S ? A101A
A ? 0A | 1A | e
```

Here,

- The non-terminal **A** can generate **any combination of 0's and 1's**, including the empty string (e).
- Therefore, the string generated by **S** must contain the substring **"101"**, with any binary string before and after it.

Hence, the language generated is:

\[
L=\{x101y \mid x,y \in \{0,1\}^*\}
\]

That is, **all binary strings containing the substring "101".**

### Examples

**Accepted Strings**

- 101
- 0101
- 1010
- 11011
- 001010
- 111010111

**Rejected Strings**

- 000
- 111
- 100
- 0110
- 0100

---

## Algorithm

1. Start the program.
2. Read the binary string.
3. Search for the substring **"101"**.
4. If the substring is found, display **"String Accepted"**.
5. Otherwise, display **"String Rejected"**.
6. Stop the program.

---

## Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];

    printf("Enter the binary string: ");
    scanf("%s", str);

    if(strstr(str, "101") != NULL)
        printf("String Accepted\n");
    else
        printf("String Rejected\n");

    return 0;
}
```

## Explanation

The program checks whether the input binary string contains the substring **"101"**.

- Since **A** can generate any sequence of `0`s and `1`s (including e), any binary string is allowed before and after **101**.
- Therefore, a string belongs to the language if and only if it contains **101** as a substring.
