# Experiment 18: Simulation of DFA for Even Number of 'a's

## Aim

To design a Deterministic Finite Automaton (DFA) using a simulator to accept strings with an even number of 'a's.

---

## Problem Statement

Design a DFA for the language of strings over $\{a, b\}$ containing an even number of 'a's.
