# Experiment 7: Checking Whether a String Belongs to the Context-Free Grammar (CFG)

## Aim

To write a C program to check whether a given binary string belongs to the language defined by the Context-Free Grammar (CFG):

```
S ? 0S1 | e
```

---

## Problem Statement

Write a C program to check whether a given string belongs to the language generated by the Context-Free Grammar:

```
S ? 0S1 | e
```

---

## Theory

A **Context-Free Grammar (CFG)** is a formal grammar in which each production rule has a single non-terminal symbol on the left-hand side. CFGs are widely used in compiler design, syntax analysis, and formal language processing.

The given grammar is:

```
S ? 0S1 | e
```

This grammar generates strings with:

- Equal numbers of `0`s and `1`s.
- All `0`s appear before all `1`s.

The language generated is:

\[
L=\{0^n1^n \mid n \ge 0\}
\]

where:
- **n** is the number of `0`s and `1`s.
- Every string has the same number of `0`s followed by the same number of `1`s.

### Examples

**Accepted Strings**

- e
- 01
- 0011
- 000111
- 00001111

**Rejected Strings**

- 0
- 1
- 011
- 0101
- 00101
- 1100

---

## Algorithm

1. Start the program.
2. Read the input binary string.
3. Count the number of leading `0`s.
4. Count the number of trailing `1`s.
5. Verify that:
   - All `0`s appear before `1`s.
   - The number of `0`s equals the number of `1`s.
6. If both conditions are satisfied, display **"String Accepted"**.
7. Otherwise, display **"String Rejected"**.
8. Stop the program.

---

## Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int len, zeros = 0, ones = 0, i;

    printf("Enter the binary string: ");
    scanf("%s", str);

    len = strlen(str);

    i = 0;

    while(i < len && str[i] == '0')
    {
        zeros++;
        i++;
    }

    while(i < len && str[i] == '1')
    {
        ones++;
        i++;
    }

    if(i == len && zeros == ones)
        printf("String Accepted\n");
    else
        printf("String Rejected\n");

    return 0;
}
```

## Explanation

The program checks whether:

- The string begins with one or more `0`s.
- All `0`s are followed only by `1`s.
- The number of `0`s is equal to the number of `1`s.

If all these conditions are satisfied, the string belongs to the language generated by the grammar **S ? 0S1 | e** and is accepted.

## Conclusion

The C program successfully checks whether a given binary string belongs to the language generated by the Context-Free Grammar:

```
S ? 0S1 | e
```

It accepts strings of the form **0n1n**, where the number of `0`s is equal to the number of `1`s and all `0`s precede the `1`s. This experiment demonstrates the application of context-free grammars in recognizing structured languages that cannot be recognized by finite automata.
