# Experiment 6: Checking Whether a String Belongs to the Given Grammar

## Aim

To write a C program to check whether a given string belongs to the grammar:

```
S ? 0S0 | A
A ? 1A | e
```

---

## Problem Statement

Write a C program to check whether a given binary string belongs to the grammar:

```
S ? 0S0 | A
A ? 1A | e
```

---

## Theory

A **Context-Free Grammar (CFG)** is a formal grammar used to describe the syntax of formal languages.

The given grammar is:

```
S ? 0S0 | A
A ? 1A | e
```

### Language Generated

The grammar generates strings consisting of:

- Equal numbers of **0's** at the beginning and end.
- Any number of **1's** (including zero) in the middle.

Mathematically, the language is:

\[
L=\{0^n1^m0^n \mid n\ge0,\; m\ge0\}
\]

where:
- **n** = number of leading and trailing 0's
- **m** = number of 1's in the middle

### Examples

**Accepted Strings**

- e
- 1
- 11
- 111
- 00
- 0110
- 001100
- 000111000
- 00111100

**Rejected Strings**

- 010
- 101
- 1100
- 0010100
- 0111000

---

## Algorithm

1. Start the program.
2. Read the input string.
3. Count the number of leading `0`s.
4. Count the number of trailing `0`s.
5. Verify that both counts are equal.
6. Check that all remaining middle characters are `1`.
7. If all conditions are satisfied, display **"String Accepted"**.
8. Otherwise, display **"String Rejected"**.
9. Stop the program.

---

## Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int len, left = 0, right = 0;
    int i, j;

    printf("Enter the binary string: ");
    scanf("%s", str);

    len = strlen(str);

    i = 0;
    while(i < len && str[i] == '0')
    {
        left++;
        i++;
    }

    j = len - 1;
    while(j >= 0 && str[j] == '0')
    {
        right++;
        j--;
    }

    if(left != right)
    {
        printf("String Rejected\n");
        return 0;
    }

    for(i = left; i <= j; i++)
    {
        if(str[i] != '1')
        {
            printf("String Rejected\n");
            return 0;
        }
    }

    printf("String Accepted\n");

    return 0;
}
```

## Explanation

The program checks whether:

- The number of leading `0`s is equal to the number of trailing `0`s.
- The middle portion contains only `1`s.

If both conditions are satisfied, the string belongs to the language generated by the grammar and is accepted. Otherwise, it is rejected.

The C program successfully checks whether a given binary string belongs to the grammar:
