# Experiment 4: Checking Whether a String Belongs to the Given Grammar

## Aim

To write a C program to check whether a given binary string belongs to the grammar:

```
S ? 0 A 1
A ? 0 A | 1 A | e
```

---

## Problem Statement

Write a C program to check whether a given string belongs to the grammar:

```
S ? 0 A 1
A ? 0 A | 1 A | e
```

---

## Theory

A **Context-Free Grammar (CFG)** is a formal grammar used to describe the syntax of programming languages and formal languages.

The given grammar is:

```
S ? 0 A 1
A ? 0 A | 1 A | e
```

Here,

- The string must **start with `0`**.
- The string must **end with `1`**.
- Between them, **A** can generate any combination of `0`s and `1`s (including the empty string).

Therefore, the language generated by the grammar is:

\[
L=\{0(0+1)^*1\}
\]

### Examples

**Accepted Strings**

- 01
- 001
- 011
- 0001
- 0101
- 011001

**Rejected Strings**

- 10
- 110
- 000
- 111
- 1001

---

## Algorithm

1. Start the program.
2. Read the input string.
3. Find the length of the string.
4. Check whether the first character is `0`.
5. Check whether the last character is `1`.
6. If both conditions are true, print **"String Accepted"**.
7. Otherwise, print **"String Rejected"**.
8. Stop the program.

---

## Source Code

```c
#include <stdio.h>
#include <string.h>

int main()
{
    char str[100];
    int len;

    printf("Enter the binary string: ");
    scanf("%s", str);

    len = strlen(str);

    if(str[0] == '0' && str[len-1] == '1')
        printf("String Accepted\n");
    else
        printf("String Rejected\n");

    return 0;
}
```

## Explanation

The program reads a binary string and checks whether it satisfies the grammar.

- The string must begin with **0**.
- The string must end with **1**.
- Any sequence of **0** and **1** is allowed between them because **A ? 0A | 1A | e**.

If these conditions are satisfied, the string belongs to the language generated by the grammar.
